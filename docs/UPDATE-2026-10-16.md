# Game update — 16 October 2026

The existing game and save schema remain in place. Rider bone lengths, normal
wheelie input and deterministic engine physics are unchanged.

- Both Supermoto levers use a fixed dark finish without extra material groups.
  The moped is 4% smaller with its indicator assemblies removed. The Töffli's
  long fork/handlebar cables are removed. Rider scale is
  compensated so the same adult skeleton and fixed-length IK remain intact.
- Ground-started wheelies receive a short front-fork load-up effect. Fast rides
  receive one bounded draw of twelve faint edge streaks. Pause/blur and reduced
  motion disable these effects.
- The sticker workshop owns a full-viewport native scroll area; all tools,
  original product imagery and Save are in normal flow. Center and mirror move
  the selected placement onto actual eligible faces without mirroring artwork.
  New copies cost one unit each; editing/removing a saved copy is free. All
  targets commit atomically, and retries do not charge an unchanged copy twice.
- Shop product coin prices follow their catalog price, with a 20% premium for
  existing glowing prints, hood adjustment or number customization. The flag
  remains 5,000 coins. Chrome stickers cost 30 coins per placement. Normal run
  income, accumulated coins and prior ownership are retained.
- Paint, rim and helmet choosers include seven distinct rainbow hues and hide
  close visual duplicates. Persisted older colors remain valid and selectable.
- Sharing uses explicit WhatsApp, Telegram and email drafts without an OS
  copy-link option. Revive uses WhatsApp or Telegram once per run. Opening a
  draft cannot prove delivery; referral rewards still require server confirmation.
- Connection failures retain the digital outbox and account identity. Specific
  temporary reward messages disappear after 3.8 seconds; pending signed proof
  retries when online. Missing initial proof is never fabricated. Actual expired
  authentication remains visible. All 3D error views offer Reload.

Only targeted CPU checks run locally. GitHub performs the complete unit,
production-build and mobile/desktop/offline browser checks before deployment.
Publishing uses GitHub's Git Data API because local git.exe has crashed.

The staff-only dashboard adds a topic selector for saved controls, device class,
quality, sound, motion, motorcycle, helmet, level and progress distributions.
It uses the existing bounded 25-customer sample. Coarse device categories are
recorded on authenticated saves; old saves remain unknown. No raw user agent,
IP address, visitor tracking or new access permission is stored or requested.
